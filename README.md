# NOT RESPONDING

NULL STUDIOによる、ブラウザ向け短編一人称ホラー。React、Three.js、Web Audioで描画・入力・音響を同期させています。外部の3Dモデルや音声ファイルに依存しません。

## 操作

- WASD / 矢印キー: 移動
- マウス: 視点操作。Pointer Lockが使えない環境ではドラッグ操作
- Shift: 速く移動
- E: PCを調べる / 画面から離れる
- モニターの顔をクリック・長押し。Space / Enterでも操作可能
- C: 異世界内のゲーム内コンソール
- Enter: コマンド実行。上下キーで入力履歴
- Esc: 一時停止 / コンソールを閉じる
- M: ミュート切り替え
- タッチ端末: 画面をドラッグして視点操作、画面左下の方向ボタンで移動

## 構成

- `src/App.tsx`: タイトル、HUD、コンソール、設定、フォーカス管理
- `src/game/Engine.ts`: 一人称入力、衝突判定、シーン遷移、強制カメラ、帰還、再プレイ
- `src/game/room.ts`: 夜の自室、家具、モニター、帰還後の異変
- `src/game/world.ts`: 青い立体世界、手掛かりの構造物、トンネル、実際に落下する足場
- `src/game/Audio.ts`: 環境音、PCの低音、足音、崩壊音、着地音
- `src/game/textures.ts`: プロシージャルな画面・素材テクスチャ

## 体験

自室でPCを調べ、BSODの顔に触れると、同じカメラがモニターの奥のトンネルを通って異世界に入ります。中心の構造物に近づくと復元コマンドを読むことができます。コンソールで復元を実行すると、入力が一時停止し、視線、亀裂、足場の落下、プレイヤーの落下が連動します。最初の自室を落下経路の下に配置して着地させ、着地後に座標をリベースするため、フェードや画面の切り替えに依存しません。

音量、ミュート、描画品質、穏やかな演出の設定はブラウザに保存されます。帰還後は操作を再開でき、PCを調べるかメニューから再プレイできます。Pointer Lockや全画面表示が拒否されても体験は継続できます。

## 実行

`npm install`後、`npm run dev`で起動できます。配信用は`npm run build`。WebGL 2対応ブラウザが必要です。Google Fontsが取得できない場合もシステムフォントで動作します。

## 手動確認項目

タイトルから開始、移動とPC調査、顔のクリック・長押し、異世界探索、コマンド誤入力、コンソールの開閉、復元イベント、帰還後の移動、再プレイを確認してください。音声ミュート、軽量描画、タブ離脱時の停止、Pointer Lock拒否時のドラッグ操作、タッチ操作も確認対象です。
